# Overview
Analyzes e-commerce sales transaction data to identify business opportunities, performance gaps, customer behavior patterns, and operational improvement opportunities.

The objective is to transform raw transaction data into actionable business insights that can help management make informed decisions about sales performance, profitability, discount strategies, customer segments, and order fulfillment.

The analysis follows a structured workflow: data understanding, data cleaning, exploratory analysis, hypothesis testing, insight generation, recommendations, and dashboard development.
